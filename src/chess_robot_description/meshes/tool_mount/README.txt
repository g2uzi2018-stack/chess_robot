tool_mount：末端安装件模型

保存 Nova5 末端安装板、夹持底座、支架及相机的固定组合模型。

当前使用
  camera_mount_assembly_m.stl：组合网格，单位为米，基准为 Link6 法兰安装面。
  camera_mount_assembly_m.json：对应网格的来源、单位换算、安装基准和坐标变换说明。

来源对照
  new_jiazhua1.STL：包含完整静态夹爪的原始复合网格，当前组合模型不引用。
  不将它作为独立支架叠加到当前模型，以免重复包含夹爪。

使用入口
  ../../urdf/nova5_with_ag95.urdf.xacro：组合模型入口，将当前网格用于显示和碰撞几何。
  ../../README.md：装配关系、参数和已知限制。

当前安装基准来自 CAD 配准，不代表已完成实物或相机光学标定。
资源用途或引用入口变化时，同步更新本提示。
