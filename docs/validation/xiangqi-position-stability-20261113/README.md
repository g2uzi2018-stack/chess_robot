# 中国象棋位置确认稳定性调整 · 2026-11-13

已部署同帧位置恢复估计器。目标是减少静止棋子频繁失去几何资格、界面闪为 PRED 的现象；本次没有证据证明绝对定位精度提高，也没有进行机械臂运动。

## 行为变化

原平面估计仍是首选路径，原先合格的位置保持原样。只有原估计以 `surface plane unreliable` 拒绝时，才使用当前帧的深度点、掩膜和中心射线重新估计中心。按射线坐标拟合逆深度，通过空间覆盖、分区中心一致性和分半中心一致性判断能否保留中心；没有历史坐标补位，没有修改类别置信度阈值，没有把二维框当作深度几何。

恢复结果含独立方法名、版本和诊断量。接收端按对应方法检查诊断量，修正此前对所有方法都硬套旧平面 RMS 上限的问题。原方法继续使用 2 mm 平面 RMS 规则。视觉节点仍不授予 motion_ready / grasp_ready。

新估计器阈值是当前场景的经验资格条件，不是传感器精度声明：保留点比例 ≥60%，四象限各 ≥50 点，空间最小轴 RMS ≥3 mm，深度残差 RMS ≤4 mm，1 mm 内残差点占比 ≥20%，留一象限中心变化 ≤1.5 mm，四个方向相对半区的中心差 ≤4 mm。误差门限与正常一致性检查没有被整体删除。

## 当前在线结果与限制

最终 120 秒观测：识别 2,651 帧，22.10 fps，每帧均检出 32 子，位置确认率 98.25%；scene 22.11 fps，结果包全部有效。网页收到了 1,708 个不同序号的新图像，释放访问租约成功。渲染棋子观测中，因相机几何显示 PRED 为 1,405 / 90,944（1.545%），另有 1,016 次因分类不确定显示 PRED。之前短窗口几何 PRED 为 16.11%，但两段不是同一时刻的严格 A/B。最终类别齐全帧占 63.90%，这不等于人工真值准确率。见 [在线汇总](live-final-summary.json)。识别按独立源帧计算，界面 PRED 按渲染的棋子观测计算，二者分母不同。额外 Python 多话题观察器有接收丢帧，其 source_subscriber_observed 不是相机输出帧率；最终采样误读了包的基座有效字段，因此该项改为 null 并记录原因，未把未测到写成 0%。

当下同现场条件 A/B：新版前段 24.49 fps，旧版 23.33 fps，新版后段 23.09 fps；几何确认率分别 98.26%、83.91%、98.20%。该测量自己的 HTTP 请求误用了控制台端口，返回 404，不能用来证明网页图像交付；ROS 测量仍有效，三段请求负载相同。最终在线观测改用正确的 8088 预览端口并独立统计成功图像。见 [A/B 汇总](controlled-ab-summary.json)。

当前帧率下降也出现在旧版，不能归因于本次恢复估计器；本次尚未恢复此前 29.76 fps 的十分钟结果。旧的 30 fps 结果不代表当前持续性能。

静止点重复性约水平 0.5 mm、深度 1.1 mm（有效观测相对各棋子中位位置的 95 分位）。有效样本选择发生变化，不能据此宣称抖动变小。没有外部位置真值、没有多摆放独立验收、没有机械臂抓取精度验收。整盘仍可能有少数拒绝，且红帅附近分类置信度徘徊是独立问题；本次没有降低分类阈值掩盖它。
