## 4. 模型、坐标与显示结论

- 链路：`dummy_link --fixed--> base_link --joint1--> Link1 ... --joint6--> Link6`。dummy→base 为恒等变换。六个 joint 都为 revolute，关节局部轴约为 +Z，关节顺序由名称 `joint1..joint6` 显式指定。
- URDF 使用米和弧度；读反馈工具需先确认设备位置为 deg、速度为 deg/s，随后乘 π/180 发布 ROS。CSV 同时保留接收 UTC ns、steady ns 和控制器原始时间戳，未经固件确认不声称其时钟语义已验证。
- `Link6` 只是 URDF 链末端；没有已验证的法兰→TCP 变换、夹爪、相机、棋盘或桌面模型。不能把它直接当作已校准 TCP。
- 原厂零位的 `base_link→Link6` 位置约为 (0.000001818, -0.223327727, 1.090000273) m；这是模型计算值。全零位的缩放 Jacobian 最小奇异值 3.9122e-22，条件数约 5.61e21，**近乎奇异，不作为本轮运动验收起点**。
- 12 个候选位形仅供未来厂家计算接口测试：固定随机种子6021、角度远离模型上下限，平移 Jacobian 行除以0.85 m 后筛选最小奇异值>=0.05、条件数<=80。实际最小值0.0520623、最大条件数41.0904。它们未做碰撞、桌面/线缆或现场清空检查，**不是可执行动作列表**。零位单列诊断。
- 二进制 STL 无内建单位。按 URDF 的米解释，网格尺度与 link 长度相容；边界与三角形数已留存。没有实物参照，因此“模型比例/零位/方向与实机一致”仍未验收。
- Xorg 存在，但 SSH `DISPLAY=:0 xdpyinfo` 返回授权错误，登录列表仅有 gdm 图形会话。没有绕过显示权限。本次未宣称 RViz 窗口加载或视觉检查通过；提供 RViz 配置供恢复桌面后使用。

## 6. 恢复连接后的实验计划（尚未执行）

1. 现场确认机器人/控制盒铭牌、固件完整版本和 TCP/IP 控制模式；核实当前 IP、布线/网段和已有控制者。只读连接成功后采集 RobotMode/GetAngle/GetPose/GetErrorID 和实时报文，并核对协议头、包长、版本对应偏移。
2. 不改配置地记录用户/工具编号及6D变换、负载/重心、全局速度、再现及缩减参数。先使 `T_base_tcp = T_base_user · T_user_tcp`、`T_base_flange = T_base_tcp · inverse(T_flange_tcp)` 与 URDF base/Link6 定义一致。V4 欧拉说明为 Rz(rz)Ry(ry)Rx(rx)，角为度；V3 必须查匹配资料，不猜姿态表示。
3. 采至少10 s静止真实反馈，统计 receive steady dt 的中位/P95/最大、控制器时间增量、丢帧/重复、时钟漂移；确认硬件关节顺序、方向、零位。真实 topic 为 `/nova5/real_joint_states`，模拟 topic 为 `/validation/synthetic_joint_states`。只有前者可支持真实链路验收。
4. 用当前安全位形与12个离线候选中可达且无奇异的多组，先做只计算的厂家 FK/IK；V3 `PositiveSolution/InverseSolution` 与 V4 `PositiveKin/InverseKin` 分开。近参考解参数按版本资料确认；不把另一个关节分支算作失败。检查 FK(IK) 的位置欧氏范数和 SO(3) 相对旋转角、解的模型/实机限位、相邻目标连续性与分支跳变。建议模型/控制器一致性阈值0.5 mm/0.1°仅供用户审议，**尚未采用或通过**。先报告原始残差和帧定义，不补偿未解释的固定偏差来“通过”。
5. 有真实起点和物理限值后，另外提交具体单关节/MovJ/MovL目标、每轴/笛卡尔范围、deg/s与mm/s、加速度、相对/绝对比例、预期路径和中止方案。现场急停、工作区和允许动作由用户确认后才实现和执行该范围。当前无法给出可信实机起止位置，**本报告不请求或暗含运动许可**。
6. 每条运动记录 UTC/steady发送、应答、队列标识（若支持）、实际开始/结束、目标、实际状态、报警与模式。完成条件由实际到位误差+速度稳定+队列/模式联合判定，不能用应答成功代替。
7. MovL 对TCP点计算到目标线段的最短距离及投影进度、姿态误差；MovJ报告关节误差、速度连续性和终点误差，不要求TCP走直线。停止响应从命令发送和应答两种起点分别计时，到速度进入静止阈值并保持为止；阈值、保持时间、观测时延均先约定，网络停止不是急停等效物。暂停/继续只按匹配版本实现，不用清报警或继续绕过安全条件。
8. 速度分档仅用已确认额定/现场范围内的保守设定。单位：deg↔rad乘π/180，mm↔m乘0.001；百分比除100。短程可能为三角速度曲线；达到v且对称加减速大致需行程>=v²/a（忽略jerk，正式以控制器曲线为准）。不知道a就不能宣布短程已达到设定速度。
9. 位置差分采用单调控制器时钟（若语义确认）或接收steady，禁止用未同步UTC直接算速度；报告原始和经明确窗口滤波后的差分、反馈速度及峰值。125 Hz是V4文档30004名义值，不是本次测得采样率；网络聚包和滤波会改变峰值估计。TCP角速度由相邻旋转矩阵的对数计算，避免直接差分有环绕的欧拉角。没有稳定样本量不宣布上限验证通过。
