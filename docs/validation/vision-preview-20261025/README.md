日期：2026-10-25（Asia/Taipei）。这些小型摘要随 Git 保存，原始图像和运行日志仍在被忽略的 `runs/` 下。

- `vision-smoke.json`：第一阶段 180 帧真实 D405 与 ROS 链路测试；当时图像发布频率与最终预览版本不同，不能用它替代最终 30 Hz 性能结论。
- `preview-30hz-lan.json`：最终压缩转发链路的 Windows → AGX 局域网不同 JPEG 收帧、带宽与资源测量；目标 30 Hz，实收约 29.4～29.7 fps。
- `source-loss.json`：最终版本通过临时 ROS 图像源验证配置扩展、过期帧拒绝、断流恢复及租约回收；不是物理拔插 D405 测试。
- 算法单元测试为 8 项（CTest 包装统计可能显示 9），覆盖深度质量、圆检测与标定映射；见包内测试及[视觉报告](../vision-node-20261025.md)。
- 不代表棋子身份识别、真实定位误差、手眼/TCP 标定、浏览器 GPU 绘制帧率或自动夹取已经验收。
