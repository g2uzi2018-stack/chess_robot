## 接入的业务与边界

- `supervised_flat_table`现场模式使用已有实抓首层名义TCP基座Z=-0.005235731876821386m，层间增加13mm；观察100mm、高位转移120mm。开爪指令raw=1000，闭合指令raw=0并要求新接触；最终夹持raw由反馈决定。旧通用标定字段不再作为该受监督模式的虚假必填项，也不伪造审查文件。
- `scan.table_contact.json`将扫描和Home恢复为普通`roundtrip_low`；仅竖直DESCEND/RETREAT使用`table_contact`，保留驱动自身的方向、行程、桌面、关节及绕转检查。主控连接现有驱动，无驱动重启、清错、使能或参考清零。
- 搬运前对真实规划轨迹检查TCP周围25mm持物包络球，要求高于当前堆顶20mm，并在搬运中监测同一高度界限；模型在启动时加载，避免持物时解析模型阻塞反馈。
- 本轮发现扫描器与主控双节点订阅造成回调积压，已同时处理两节点就绪队列。夹爪驱动的既有`feedback_max_age_sec=1.0`在启动时读取，客户端按“设备年龄+消息延迟”核对该期限；没有修改驱动参数。无效反馈、掉落与持物丢失仍会停止。
- 粗扫描只提供搜索种子。“任意棋子”任务可在首次近距离窗口建立一致的新类别；后续夹取窗口仍要求同一类别，不接受unknown/冲突。资格不合格目标在夹取前跳过，但仍作为真实邻居保留。
- `controller_epoch`实际是停稳审计令牌，运动后会更新，不是硬件开机ID。跨真实对齐运动比较相机/模型/源身份，运动后重建停稳窗口；下降前再次绑定新停稳令牌。单个窗口内令牌或身份改变仍拒绝。
- 放稳观察不执行抓取动作，不再套用抓取阶段的邻居间距或每帧文字分类条件；它核对独立两秒、至少20帧、唯一顶面位置、几何重复性和相对堆高，并继续要求现场放稳确认。第一层实测相机Z作为相对基准，以避免已知绝对Z偏差。
- 已完整扫描的同轮清单可在900秒内作为继续任务的搜索提示，必须实际到位重观；不把旧坐标当作下降授权。第一颗释放后未提交的状态支持先重观/确认放稳再续接，避免重复抓放。此恢复绑定原始结果及空夹爪状态，不能跳过实体核对。
