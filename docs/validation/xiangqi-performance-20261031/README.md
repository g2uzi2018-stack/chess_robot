# 象棋视觉优化摘要证据（2026-10-31）

这些文件是现场采样的结构化摘要，便于克隆仓库后审查；不是新运行的测试或固定性能承诺。

| 文件 | 范围 |
| --- | --- |
| `parallel-live-before.json` / `parallel-live-after.json` | 不同现场窗口7.4→15.6Hz；并非固定输入的单因素对照 |
| `parallel-equivalence.json` | 3保存帧、9组全图/ROI、34检测对照，错配拒绝、共享槽释放及实际CPU/GPU重叠 |
| `geometry-regression.json` | 固定检测输出与36组合成样例的一致性及交替计时；不等于标注集准确率 |
| `geometry-replay-after.json` | 固定108帧回放18.98帧/s，不是新实机三维识别FPS |
| `camera-30hz.json` | SDK模式、校正像素对照、30秒900组交付、局域网唯一JPEG序号统计；暗场且无机械臂反馈 |

`stamp`为主机从SDK取出帧时记录的时间，不是曝光时间。发布延迟从该时间计到识别发布；900组同stamp验证四路消息交付完整，不能证明曝光时刻与机械臂硬件同步。

原始RGB-D、运行日志、构建、回退二进制和跟踪状态仍位于各报告列出的现场`runs/`目录；外部best.pt位于训练工程，均未随本仓库分发。完整实机负载、实体准确率与真实移动/遮挡跟踪仍待验收。
