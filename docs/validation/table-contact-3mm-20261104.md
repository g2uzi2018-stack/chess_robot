## 规则

不把全局20mm改成3mm。候选保留全部机械臂碰撞外形、相机/夹爪固定本体和21种开度几何，将活动左、右夹指组件单独建凸包。

- 普通配置与普通运动：所有非base外形仍距真实桌面至少20mm。
- 只有显式 `table_contact` profile 的 `DESCEND` / `RETREAT`：目标XY半径80mm内，活动夹指组件允许最小3mm；相机、固定夹爪本体和机械臂连杆仍20mm。
- 区域外仍20mm，低于3mm仍拒绝。PREGRASP、HOME、GRASP_SEQUENCE和关节点动不能使用此例外；竖直行程最多150mm，原方向/对齐/姿态/关节/扭转/雅可比/自碰撞检查保留。
- 候选profile速度0.05rad/s、加速度0.10rad/s²；桌面base_z仍为-0.010m，工作区下界候选为-0.010m。

3mm指**模型最低外形到桌面的最小允许间隙**，不是把TCP设成距桌3mm，也不是已证明实物误差小于3mm。

目前候选仅用于受监督空爪接近/撤离与观察。被持棋子、增长中堆叠的额外碰撞体没有在本改动中实现；不能把这次验证当作完整自动夹取验收。没有修改TCP、URDF、参考基准或检查点identity，也没有改变碰撞检测等级或碰撞后行为。

## 代码与模型

`GeometryGuard::check()`保持原普通检查，`checkTableContact()`增加目标局部检查。ROS动作处理仅向通过 `validateTableContactGoal()` 的显式竖直目标提供局部上下文，该上下文属于本次Action，不是全局可遗留的模式。MoveArm接口定义不变。

`generate_table_contact_geometry.py`从原URDF collision STL重建21种开度，保留原7个臂段凸包，将原末端合并包络拆成固定本体与左右活动夹指。输入与输出双向凸包包含性、全部输入网格顶点包含性误差小于1e-8m，确认没有删掉原几何。原 `nova5_ag95_geometry.yaml`不变；新文件使用`.candidate.yaml`。

构建位于 `runs/table_contact_20261104_review/{build,install}`，五个相关包成功编译。未更改`.runtime/arm-install-prefix`或原service；当前以临时服务运行候选版，原service停止。

## 离线验证

临时C++程序连接真实生产Planner/GeometryGuard库，使用同一URDF的数值IK，不创建ROS节点、驱动或SDK连接。绕转状态仅为离线合成路径，未当作真实历史恢复资格。15项检查全部通过：

- 记录的普通观察姿态通过；普通20mm规则仍拒绝低位。
- 目标区域内3mm规则允许当前代表性名义棋面点；低于3mm、区域外低位被拒绝。
- HOME、PREGRASP、GRASP_SEQUENCE、Joint不能进入接触例外；超过150mm竖直行程拒绝。
- 全局clearance设成3mm仍拒绝，旧几何文件不能隐式获得例外。
- 数值IK下生产Planner完整竖直路径通过；从低位竖直撤回到原普通安全高度也通过。

代表性名义TCP终点base_z=-0.003910m。离线路径101个样本、3秒；全21开度模型中活动夹指最小距桌约5.267mm，其余部件最小约71.460mm。因此这条目标路径无需把其余部件也降成3mm。

这不是现场SDK的PLAN_READY结果，也没有验证实物3mm绝对精度。当前相机测得棋面与“桌面+13mm棋厚”约7mm不一致；开爪实物尺量与模型也约有8mm不一致，尚未解释。机械臂碰撞后反应与当前碰撞设置未核验，不作为避碰或必定断电的保证。

临时验证源码、二进制和临时错误模型用后删除；不新增持久化测试文件，不使用冒烟测试。机器可读证据在本目录同名子目录，原始运行在`runs/table_contact_20261104_review/`。
