# 2026-11-06 视觉不确定时的小步主动观察

用户要求：遇到此前轮廓缺失或复核不唯一时，先尝试可行的小幅下探观察，再决定是否退出。此变更接入现有 row 业务，没有修改视觉模型、批处理服务、速度、接触高度或原邻居/占位门限。

## 实现与默认配置

tools/pick_stack/ros_io.py 的 observe_with_approach 包装抓取目标资格、放前空槽和放后/原位落位复核。tools/pick_stack/demo.row.live.json 增加 active_observation：enabled=true，drop_offsets_m=[0.01,0.02]，min_tcp_base_z_m=0.11，含中文说明；demo.py 校验有限候选和高度下限。

候选高度按标准观察位计算，不按当前低位重复累计。源/放后为 130/120 mm，持物放前为 133/123 mm。保持当前 XY 和已用朝向，只能在标准高空观察带内启动，不能从 Home 一次下探到这些低位。

每次先通过原 table_contact DESCEND 纯规划；检查采样 FK 全路径不低于观察下限，XY 偏移不超过 3 mm，且不向上越出起点 1 mm 范围。持物时校验原 25 mm 棋子球包络，当前原最低持物 TCP 为 48 mm，观察下限默认 110 mm。发送前再次检查起点及新鲜场景身份，执行时以实测反馈监视高空下限。

仅对既有明确的视觉不确定错误尝试复查：完整观察超时、轮廓不完整、落位目标不唯一、目标关联缺失/不唯一。真实占位、邻近物体、移动/抖动超限、参考/反馈或相机身份异常、中断不会触发。完成的非执行 PLANNING_FAILED 可以跳过到下一候选；执行错误、未知应答、参考故障不会被当作可重试规划。

新视点必须重新取得原 20 独立帧/2 秒完整窗口。空槽成功后保持该视点，并保留最终下降前再次核验；已释放棋子的复核成功后受检抬回原观察高度。动作失败不自动释放或重试。

## 验证

结果目录 runs/active_observation_20261106_01。behavior-validation.json 记录 14 项针对性检查：双步顺序与持物包络；跨调用高度不累加；占位/邻居/反馈/中断/目标移动不触发；新鲜帧和身份要求；规划拒绝不执行；关闭开关；非竖直规划拒绝；Action 只接受明确非执行规划失败；空爪运行时下限；不能从 Home 发起大下探；规划期间相机丢失阻止发送；放后成功抬回；持物空槽成功保留低位。测试源以内联方式运行，未生成持久化测试源。

现场只规划结果 live-plan-only/validation.json：当前 Home XY、TCP Z=272.960 mm，分别规划 DESCEND 到 133/123 mm。两条均 PLAN_READY，采样 178/184 点，最低采样 TCP 分别 132.672/122.671 mm，最大横向偏差约 4.8 微米；假设持物包络均高于原最低限值。physical_motion_goals=0，gripper_goals=0，前后实测 TCP 漂移小于 1 微米，空爪保持 Home。

这些证明分支和规划约束通过，不代表每个业务槽位都可规划或低位一定能识别成功。真实在槽位遇到视觉故障后自动下探再复核，尚未实机触发测试。
