# 中国象棋夹取

使用越疆 Nova5 机械臂开展中国象棋棋子的识别、定位与夹取。

## 当前状态

- 项目已初始化，功能代码尚未开始。
- 开发目录：`~/workspace/chess_robot`。
- 开发机基线：Jetson / aarch64 / Ubuntu 22.04.5 LTS。
- 现有 [nova](https://github.com/g2uzi2018-stack/nova) 项目中有已能控制机械臂的参考代码（用户确认）；本仓库尚未迁移或验证这些功能。

## 后续待确认

- 相机、夹爪与棋子的规格及安装方式。
- 控制器固件、协议版本与现有 SDK 的对应关系。
- 棋盘坐标、相机标定与机械臂坐标转换。
- 单棋子夹取的执行流程、停止处理与验收标准。

## 开发约定

- 以现有可用控制代码为参考基线，SDK 更新按实际需求逐项验证。
- 现场配置与凭据保留在版本库之外；不提交私钥、密码或令牌。
- 模型、训练数据和运行输出按需单独管理。

初始化日期：2026-10-20（Asia/Taipei）。
